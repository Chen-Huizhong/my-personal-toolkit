# Toolkit

This is the toolkit of Huizhong Chen. For now, the toolkit has:

`widgets`: Some widgets that I could utilize when coding or some interesting widgets I could play.

`config`: Some configurations for specified software.

> Note: Create link when you neede to use these configurations.

## matlab

Some convenient functions in MATLAB.

## vim

My Vim configuration file `.vimrc` there.

The installations of plugins are written in `.vimrc`.

## python

Some small and easy but interesting Python programs.

For now, this folder contains:

* MineSweeper auto-click
* Interpolation func
* timer module

In the future, there might be more interesting programs.

## vsc

My configuration `settings.json`.

`Windows.settings.json` is for **Windows**.

`MacOS.settings.json` is for **MacOS**.

`keybindings.json` is the keybinding configuration, which is compatible for 
different operation systems. 

## git

My configuration `.gitconfig` for `Git`.

## powershell

My configuration for `PowerShell` on Windows.

## shell

My configurations `.tmux.conf` for `tmux` and `.zshrc` for `zsh`.

For `zsh`, I mainly use `oh-my-zsh`.
